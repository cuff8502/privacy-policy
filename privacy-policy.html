EduHelper 개인정보 처리방침

  • 시행일: 2026년 7월 14일
  • 최종 수정일: 2026년 7월 14일
  • 적용 대상: Microsoft Store 등을 통해 배포되는 EduHelper 데스크톱 앱(아래 DPAPI 보호는 Windows 1.7.0.0 이상)

EduHelper(이하 “앱”)는 교사의 업무를 돕는 로컬 중심 데스크톱 앱입니다. 앱의 주요 작업 데이터는 사용 중인 PC에 저장되지만, 학교 검색·급식·학사일정·공휴일 조회와 사용자가 선택한 외부 링크 또는 나이스 바로 입력 기능에는 네트워크나 다른 프로그램이 사용됩니다. 따라서 앱은 오프라인 전용 프로그램이 아닙니다.

1. 앱이 처리하는 정보

앱은 사용자가 기능을 이용할 때 다음 정보를 처리할 수 있습니다.

구분 예시 기본 처리 위치
교사 설정 담당 역할, 담당 학년·교과, 수업 알림 시간표, 도구 배치·표시 설정, 테마·스킨 설정 사용자 PC
학교 정보 검색어로 입력한 학교명, 선택한 학교명·학교 코드·교육청 코드, 나이스가 제공한 학교 주소·전화번호·홈페이지, 학사일정 캐시 사용자 PC 및 아래에 적은 나이스 Open API
학생 및 학급 정보 학생 이름 또는 사용자가 부여한 식별자, 모둠·좌석·RPG 상태, 발표 순서, 과제 확인, 학생 뽑기 기록, 학생 관련 메모와 연결 정보 사용자 PC
교사 작성 자료 메모, 일정, 평가·생활기록부 보조 문장, 알림장 문구, 휴지통·보관함·변경 기록 사용자 PC
사용자가 불러오거나 내보낸 자료 클립보드에서 가져온 명단·문장, 사용자가 저장한 CSV·PDF·이미지 등의 파일 사용자 PC 및 사용자가 선택한 저장 위치
화면 캡처 사용자가 화면 캡처·고정을 실행했을 때의 화면 이미지 실행 중 메모리

앱은 학생 정보를 직접 요구하는 온라인 회원가입 기능을 제공하지 않습니다. 다만 교사가 앱의 명단, 메모, RPG, 과제 확인 등의 기능에 학생 정보를 입력하면 해당 정보가 로컬 작업 데이터에 포함될 수 있습니다.

2. 로컬 저장 위치와 보안

주요 작업 데이터는 Godot의 앱별 user:// 폴더에 저장됩니다. 운영체제에서의 실제 경로는 사용자 계정과 설치 방식에 따라 달라집니다.

  • desk_live.json: 메모, 일정, 교사·학교 설정, 학생 명단과 각 도구의 작업 상태 등
  • rpg_recovery.json: RPG 복구용 스냅샷
  • 보호 대상 내부 파일: desk_live.json, rpg_recovery.json, RPG 복구 백업, 사용자가 별도로 설정한 나이스 API 인증키, RPG 검색어·태그 프리셋과 구버전의 내부 메모·디지털 책상 저장 파일
  • 그 밖의 비민감 앱 설정 파일: 테마, 소리, 도구별 화면 상태 등

EduHelper Windows 1.7.0.0 이상 배포판은 위 보호 대상 내부 파일을 Windows 데이터 보호 API(DPAPI)의 현재 사용자 범위로 암호화합니다. 1.7.0.0보다 앞선 버전은 일부 내부 작업 파일을 평문으로 저장했을 수 있습니다. 암호문은 해당 Windows 사용자 계정과 앱이 지정한 파일 용도에 묶이므로, 일반적으로 다른 사용자 계정이나 다른 PC로 복사해서는 해독할 수 없습니다. 이 보호는 Windows 계정 보안 자체를 대신하지 않으므로 공용 PC에서는 계정을 분리하고 화면 잠금과 디스크 암호화도 함께 사용해 주세요.

1.7.0.0 이상 앱이 암호화 기능 적용 전에 만들어진 정상 평문 파일을 발견하면, 현재 저장 파일과 구버전에서 사용한 정해진 내부 저장 경로만 검사합니다. 앱은 먼저 같은 내용을 담은 암호화 백업을 만들고 복호화·길이·무결성과 해당 파일 형식을 확인한 뒤 본 파일을 교체합니다. 어느 단계에서든 실패하면 기존 본 파일을 바꾸거나 초기화하지 않고 해당 파일의 저장을 중단합니다. 주요 작업 저장소를 안전하게 열 수 없으면 빈 상태에서 새 작업이 유실되지 않도록 안내 후 앱을 종료합니다. 이관 전 백업도 평문이 아니라 같은 Windows 사용자 범위로 암호화됩니다.

사용자가 명시적으로 저장한 CSV·PDF·HTML·ICS·PNG 등의 내보내기 파일은 Excel, 브라우저, PDF 뷰어 등에서 열 수 있도록 DPAPI 내부 저장 대상에 포함하지 않습니다. 해당 파일은 앱의 삭제 기능과 별개이므로 저장 위치, 공유 범위와 삭제를 사용자가 직접 관리해야 합니다.

3. 네트워크 요청과 제3자 서비스

앱은 다음 서비스에 연결할 수 있습니다. 일반적인 인터넷 통신 과정에서 각 서비스 제공자는 IP 주소, 접속 시각 등 표준 네트워크 정보를 처리할 수 있으며, 그 처리는 각 제공자의 정책을 따릅니다.

나이스 교육정보 개방 포털 Open API

호스트: https://open.neis.go.kr

기능 API 전송되는 주요 값
학교 검색 schoolInfo 사용자가 입력한 학교명 검색어, 응답 형식·페이지 값, 사용자가 별도로 설정한 경우 API 인증키
급식 조회 mealServiceDietInfo 교육청 코드, 학교 코드, 조회 날짜, 식사 구분, 사용자가 별도로 설정한 경우 API 인증키
학사일정 조회 SchoolSchedule 교육청 코드, 학교 코드, 조회 시작·종료 날짜, 사용자가 별도로 설정한 경우 API 인증키

나이스 Open API는 앱에 인증키를 내장하지 않고도 조회할 수 있으며, 사용자가 자신의 인증키를 별도로 설정한 경우에만 요청에 함께 보냅니다. 이 조회 요청에는 앱에 저장된 학생 명단이나 학생별 기록을 포함하지 않습니다. 선택한 학교 정보와 받아 온 학사일정은 빠른 표시를 위해 사용자 PC에 저장될 수 있으며, 급식 결과는 현재 사용 중인 화면에 표시됩니다.

Apple 공개 대한민국 공휴일 캘린더

호스트: https://p03-calendars.icloud.com

달력의 대한민국 공휴일을 가져오기 위해 공개 iCalendar 파일을 요청합니다. 앱의 학생 명단, 메모 또는 교사 작성 자료를 요청 본문으로 보내지 않습니다. 받아 온 공휴일과 조회 범위·시각은 로컬 캐시로 저장될 수 있습니다.

Microsoft Store

Microsoft Store를 통한 설치, 업데이트 또는 유료 디지털 콘텐츠 구매가 제공되는 경우 Microsoft가 계정, 거래, 결제 및 라이선스 정보를 처리합니다. 앱 개발자는 사용자의 전체 결제수단 정보를 직접 저장하지 않습니다. 앱에는 구매한 콘텐츠의 사용 가능 여부와 스킨 선택 상태가 저장될 수 있습니다.

사용자가 직접 여는 외부 페이지

앱의 버튼을 눌렀을 때 기본 브라우저에서 Microsoft Store, GitHub 도움말·업데이트 내역, Google 설문지·스프레드시트, 인디스쿨, Canva 도움 자료, YouTube 검색 등의 페이지가 열릴 수 있습니다. 페이지를 여는 것은 사용자의 명시적인 동작이며, 이후 입력하거나 제출하는 정보에는 해당 사이트의 개인정보 처리방침이 적용됩니다.

4. 나이스 바로 입력과 로컬 자동화

나이스 바로 입력은 사용자가 문장 입력을 실행할 때 동작하며, 화면의 나이스 ON/OFF 설정으로 끌 수 있는 기능입니다.

  • Windows에서는 앱이 로컬 PowerShell 보조 프로그램을 실행합니다. 이 프로그램은 실행 중인 브라우저 창과 창 제목, 현재 포커스된 입력 요소를 로컬에서 확인하고, 클립보드 붙여넣기 또는 Windows UI Automation을 이용해 선택한 나이스 입력 칸에 문장을 입력합니다.
  • 지원 환경에 따라 앱이 127.0.0.1의 로컬 루프백 서버와 브라우저 자동화 연결을 사용할 수 있습니다. 입력 문장은 이 PC 안에서 앱과 로컬 보조 프로그램 사이에 전달됩니다. 127.0.0.1 연결은 개발자가 운영하는 인터넷 서버가 아닙니다.
  • 자동화 과정에서 문장은 클립보드에 기록될 수 있습니다. 입력 후에는 클립보드에 해당 문장이 남을 수 있으므로 공용 PC에서는 다른 내용으로 덮어쓰거나 클립보드 기록을 지워 주세요.
  • 문장이 사용자가 로그인한 나이스 웹페이지에 입력된 이후의 저장·전송은 나이스와 사용 기관의 정책 및 사용자의 최종 제출 동작에 따릅니다.

앱은 나이스 자동입력 문장을 개발자가 운영하는 서버로 보내지 않습니다.

5. 클립보드와 화면 캡처

클립보드

앱은 사용자가 붙여넣기·가져오기·복사·나이스 바로 입력을 실행할 때 클립보드를 읽거나 씁니다. 예를 들어 반편성 명단 또는 QR 입력값을 가져오고, 생성한 문장·명단·경로를 복사할 수 있습니다. 앱은 클립보드를 지속적으로 감시하지 않습니다.

화면 캡처·고정

사용자가 화면 캡처 도구 또는 단축키를 실행하면 영역 선택을 위해 현재 마우스가 있는 모니터 화면 전체를 일시적으로 메모리에 가져온 뒤, 사용자가 선택한 영역을 잘라 고정창에 표시합니다. 현재 구현은 캡처 이미지를 자동으로 파일에 저장하거나 외부 서버에 업로드하지 않습니다. 선택 화면과 고정창을 닫거나 앱을 종료하면 해당 이미지는 실행 중 메모리에서 해제됩니다. 운영체제에 따라 화면 기록 권한이 필요할 수 있습니다.

6. 보유 기간과 삭제 방법

개발자가 운영하는 서버에는 앱의 로컬 작업 데이터를 보관하지 않습니다. 사용자 PC의 데이터는 사용자가 앱 안에서 삭제하거나 앱 데이터 폴더를 지울 때까지 남을 수 있습니다.

  • 메모 등 삭제 항목은 먼저 휴지통에 남을 수 있으며, 휴지통 비우기(완전삭제)를 실행해야 휴지통 기록에서 제거됩니다.
  • 보관함의 삭제 기록·증빙·변경 기록은 보관함에서 별도로 영구 삭제할 수 있습니다.
  • 새 학년 시작 시 앱은 학생 명단, 좌석·모둠 연결 및 일부 학생 도구 기록의 초기화를 안내할 수 있습니다.
  • 새 학년 초기화가 모든 관련 데이터를 지우는 것은 아닙니다. 메모 본문, 휴지통·보관함, RPG 로그·복구 데이터, 사용자가 내보낸 파일 등은 별도로 확인하고 삭제해야 합니다.
  • 학교 연결 해제는 현재 교사 설정과 급식 도구의 학교 연결 정보를 지웁니다. 이미 받아 둔 학사일정·공휴일 캐시는 앱 데이터 전체를 지우거나 새 데이터로 대체되기 전까지 남을 수 있습니다.
  • 앱을 제거한 뒤에도 운영체제 정책에 따라 사용자 데이터 폴더나 사용자가 내보낸 파일이 남을 수 있습니다. 완전 삭제가 필요하면 운영체제의 앱 데이터 초기화 기능을 사용하거나 EduHelper의 사용자 데이터 폴더와 내보낸 파일을 직접 삭제해 주세요.

로컬 데이터는 개발자가 원격으로 열람하거나 대신 삭제할 수 없습니다. 삭제 방법에 도움이 필요하면 아래 연락처로 문의해 주세요. 문의 메일에는 실제 학생 명단이나 민감한 학생 정보를 첨부하지 않는 것을 권장합니다.

7. 학생 정보 이용 시 사용자 책임

앱은 교사가 학교 업무를 위해 사용하는 보조 도구입니다. 사용자는 소속 기관의 개인정보 보호 지침과 관련 법령에 따라 학생 정보를 입력할 적법한 권한이 있는지 확인하고, 필요한 최소 정보만 입력해야 합니다. 민감정보나 불필요한 가족·건강·상담 정보는 앱에 입력하지 않는 것을 권장합니다.

8. 정보의 판매, 광고 및 분석

앱 개발자는 앱에 입력된 개인정보를 판매하거나 임대하지 않습니다. 현재 앱에는 맞춤형 광고를 위한 추적 기능이나 개발자 운영 서버로 사용 기록을 자동 전송하는 분석 기능이 포함되어 있지 않습니다. 제3자 웹페이지나 Microsoft Store를 사용자가 이용할 때의 처리는 각 서비스의 정책을 따릅니다.

9. 방침 변경

기능, 외부 서비스 또는 법적 요구사항이 바뀌면 이 방침도 수정될 수 있습니다. 중요한 변경은 이 문서의 최종 수정일과 앱 또는 배포 페이지의 안내를 통해 알립니다.
