EduHelper 이용약관

시행일 2026년 11월 5일

이 약관은 CulCher가 제공하는 EduHelper 데스크톱 앱과 앱에서 선택해 사용하는 Microsoft 계정 연결에 적용됩니다.

1. 앱 사용과 업무자료

EduHelper는 교사의 수업과 학교 업무를 돕는 소프트웨어입니다. 생성된 문장과 자동 입력 결과는 교사가 최종 확인합니다. 학생 정보가 포함된 자료는 학교의 개인정보 보호 기준에 따라 관리하며, 외부 연결 기능을 사용하기 전에 학교의 외부 서비스 이용 기준을 확인합니다.

2. Microsoft 계정과 OneDrive

로컬 기능은 Microsoft 계정 없이 사용할 수 있습니다. Microsoft 계정 연결, OneDrive 백업·복원과 지원되는 버전의 캘린더·메모 자동 연동은 각각 선택할 수 있습니다. 연결을 선택하면 Microsoft의 공식 화면에서 본인 확인과 권한 동의가 이루어집니다.

백업과 연동 자료는 암호화해 OneDrive의 EduHelper 전용 폴더에 보관합니다. 새 기기에서 자료를 열려면 같은 Microsoft 계정과 복구 암호가 필요합니다. 복구 암호와 별도 파일 백업은 안전한 위치에 보관하세요.

기기에서 연동을 끄면 이후 자동 송수신이 중단됩니다. 기존 OneDrive 사본은 OneDrive에서 관리하며, Microsoft가 부여한 앱 접근 권한은 Microsoft 계정에서 철회할 수 있습니다. 자료 처리 범위와 삭제 방법은 Microsoft 계정·OneDrive 개인정보 안내에서 확인할 수 있습니다.

3. 앱 콘텐츠와 외부 서비스

EduHelper 자체 코드·콘텐츠와 유료 스킨의 무단 복제와 재판매는 허용되지 않습니다. 오픈소스 소프트웨어, 글꼴과 제3자 자료에는 각각 고지된 라이선스가 적용됩니다.

Microsoft 계정과 OneDrive 이용에는 Microsoft의 서비스 조건이 적용됩니다. Microsoft Store에서 구매하는 유료 콘텐츠의 가격, 이용 기간과 결제 조건은 구매 화면에서 확인할 수 있습니다.

4. 개인정보와 문의

개인정보의 처리 항목, 보유·삭제 기준과 이용자 권리는 EduHelper 개인정보 처리방침에 안내되어 있습니다. 앱과 약관에 관한 문의는 CulCher 문의 메일로 보낼 수 있습니다.
